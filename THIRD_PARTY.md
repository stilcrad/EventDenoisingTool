# Third-party dependencies

NumPy, PyTorch, Numba, scikit-learn, h5py and the other Python packages are dependencies installed separately. Their licenses remain applicable.

EBIV and event-based BOS solver repositories are not vendored into this candidate. Obtain them from the original authors and verify the applicable licenses and data terms before redistribution or building a combined release.

The historical EBIV benchmark wrapper is included for provenance. It does not include the solver implementation or the recording required to run it. Its remaining dependency mapping is documented in `docs/REPRODUCTION.md`.

This file is an inventory for release review, not a completed license clearance. No project license is granted by this inventory.
